## 🎯 When to Use Each Indicator

### Use Pentarch When...
- ✅ You want to identify market cycle phase
- ✅ Looking for early-cycle (TD, IGN) or late-cycle (WRN, CAP, BDN) signals
- ✅ Day trading or swing trading volatile assets
- ❌ Avoid: Scalping <15m, low volatility periods

### Use Janus Atlas When...
- ✅ You need specific price levels for entries/exits
- ✅ Setting stop losses and take profits
- ✅ Any trading style, any timeframe
- ❌ Avoid: Parabolic moves, newly listed assets

### Use Omnideck When...
- ✅ You want comprehensive 8-system analysis
- ✅ You're an advanced trader with 100+ hours to invest
- ✅ You understand TD Sequential, VWAP, oscillators
- ❌ Avoid: Beginners, visual complexity intolerance

### Use Augury Grid When...
- ✅ You trade multiple assets and need daily screening
- ✅ Morning market scan to find best setups
- ✅ Crypto altcoin trading, sector rotation analysis
- ❌ Avoid: Single-asset focus, position traders

### Use Volume Oracle When...
- ✅ You need volume confirmation for patterns/levels
- ✅ Identifying breakout vs fake-out
- ✅ Tracking open position P&L
- ❌ Avoid: Spot forex (use futures), very long timeframes

### Use Harmonic Oscillator When...
- ✅ You want real-time momentum confirmation
- ✅ Need to know if market is overbought/oversold
- ✅ Filtering setups with momentum agreement
- ❌ Avoid: Very long timeframes (too noisy)

### Use Plutus Flow When...
- ✅ You want to spot price-volume divergences
- ✅ Identifying accumulation/distribution
- ✅ Swing trading reversal setups
- ❌ Avoid: Scalping, spot forex (use futures)

## 🔗 Best Indicator Combinations

### The Trinity ⭐⭐⭐⭐⭐ (Most Popular)
**Pentarch + Janus Atlas + Volume Oracle**
- Cycle phase + Price levels + Volume confirmation
- Highest probability when all 3 align
- Best for: Day trading, swing trading

### The Foundation ⭐⭐⭐⭐ (Beginner-Friendly)
**Janus Atlas + Volume Oracle**
- Price levels + Volume confirmation
- Simple, visual, intuitive
- Best for: Beginners, level traders

### The Momentum Stack ⭐⭐⭐⭐
**Pentarch + Harmonic Oscillator**
- Cycle phase + Momentum confirmation
- Early-cycle with momentum = strong setup
- Best for: Day trading, capturing moves with momentum

### The Divergence Hunter ⭐⭐⭐⭐
**Plutus Flow + Pentarch + Janus Atlas**
- Divergence + Cycle shift + Entry level
- Excellent for spotting reversals
- Best for: Swing trading tops/bottoms

### The Scanner ⭐⭐⭐⭐
**Augury Grid + Any Indicator**
- Screen 20-50 assets, detailed analysis on filtered
- Morning routine: Grid scan → Trinity on best 3
- Best for: Multi-asset traders

## 📋 Signal Quick Reference

### Pentarch (5 signals)
- 🟣 **TD** - Accumulation (early bullish)
- 🩵 **IGN** - Markup (bullish momentum)
- 🟡 **WRN** - Distribution (late-cycle caution)
- 🟠 **CAP** - Climax (exhaustion)
- 🔴 **BDN** - Decline (bearish shift)

### Harmonic Oscillator (4 signals)
- 🟢 **BUY** - 3+ oscillators bullish
- 🔴 **SELL** - 3+ oscillators bearish
- 🔵 **STRONG** - 5+ oscillators agree (extreme)
- ⚪ **NEUT** - Neutral (no consensus)

### Janus Atlas (50+ level types)
- **Core 5:** dH, dL, wH, wL, dVWAP
- **All 50+:** Daily, Weekly, Monthly, Quarterly, Yearly, Session, VWAP, Volume Profile, Market Structure, Opening Range, Killzones, Gap Levels

### Volume Oracle (3 systems)
- **System 1:** Volume Flow (green/red bars)
- **System 2:** Volume Zones (accumulation boxes)
- **System 3:** Position Manager (P&L tracking)

### Plutus Flow (divergences)
- **Bullish Divergence:** Price ↓, OBV ↑ (accumulation)
- **Bearish Divergence:** Price ↑, OBV ↓ (distribution)

## ⚠️ Common Mistakes to Avoid

1. ❌ **Using too many indicators at once**
   → ✅ Start with 1-2, add gradually

2. ❌ **Skipping the learning curve**
   → ✅ Observe 20-30 signals before trading

3. ❌ **Trading every signal**
   → ✅ Wait for high-confluence setups (multiple confirmations)

4. ❌ **Ignoring timeframe suitability**
   → ✅ Pentarch needs 15m minimum, Janus works on all

5. ❌ **No paper trading**
   → ✅ Practice 2-4 weeks before risking capital

# Page 2: Visual Signal Guide

## 🎨 Pentarch Signal Visual Guide

```
BULLISH (Bottom Signals):          BEARISH (Top Signals):
🟣 TD  - Below candle               🟡 WRN - Above candle
🩵 IGN - Below candle               🟠 CAP - Above candle
                                   🔴 BDN - Above candle

Pilot Line Colors:
🔵 Blue  = Bearish regime
🟢 Green = Bullish regime
⚪ Gray  = Neutral
```

## 📊 Volume Oracle Visual Guide

```
Volume Flow Bars:
🟢 Green = Buying pressure (volume + price up)
🔴 Red   = Selling pressure (volume + price down)
⚪ Gray  = Neutral/low volume

Volume Zones:
📦 Boxes = High-volume accumulation areas

Position Manager:
💙 Blue line  = Entry price
🟢 Green P&L  = Profitable position
🔴 Red P&L    = Losing position
```

## 🎯 Harmonic Oscillator Visual Guide

```
Signals (based on 7-oscillator voting):
🟢 BUY    = 3-4 oscillators bullish
🔴 SELL   = 3-4 oscillators bearish
🔵 STRONG = 5+ oscillators agree (very strong)
⚪ NEUT   = <3 votes (no consensus, choppy)
```

## 📈 Janus Atlas Visual Guide

```
Level Line Colors (customizable):
Daily levels:     Usually yellow/orange
Weekly levels:    Usually blue/purple
Monthly levels:   Usually red/pink
VWAP:             Usually green
POC/VAH/VAL:      Usually gray/white

Labels show level type (dH, WL, POC, etc.)
```

## 🔄 Plutus Flow Visual Guide

```
OBV Line:
🟢 Rising OBV  = Accumulation
🔴 Falling OBV = Distribution

Divergences:
📈 Price up + 📉 OBV down = Bearish divergence (distribution)
📉 Price down + 📈 OBV up = Bullish divergence (accumulation)

Trend Ribbons:
🟢 Green ribbons = Bullish OBV trend
🔴 Red ribbons   = Bearish OBV trend
```
